\section{The problem}
I want to be able to input a chain of structures 
that define what I want a device to support.
Then the program returns a logical device that has that support.

\section{The issue}
The list of structures is very long, fix by parsing \textit{vk.xml}.

Though the main problem is that compairing two structures is nigh
impossible based on \textit{vk.xml}
